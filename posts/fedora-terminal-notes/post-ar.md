# إعداد الطرفية الخاصة بي على Fedora

أستخدم **الطرفية (Terminal)** بشكل كبير في مختبرات الشبكات والبرمجة وإدارة الأنظمة.

![سير عمل الطرفية](images/terminal.svg)

## سير العمل الأساسي

1. تحديث النظام.
2. تثبيت الأدوات التي أحتاج إليها.
3. تنظيم ملفات الإعدادات.
4. التحقق من النتيجة من خلال الطرفية.

## أوامر مفيدة

على سبيل المثال، يعرض الأمر `fastfetch` نظرة سريعة على الجهاز، بينما يعرض الأمر `ip addr` واجهات الشبكة.

```bash
sudo dnf upgrade
ip addr
ss -tulpn
git status
```

## مثال بسيط على Bash

```bash
#!/usr/bin/env bash
set -euo pipefail

echo "Current hostname: $(hostname)"
echo "Current user: $USER"
```

## ملاحظات

تساعد العادات الجيدة في استخدام **Shell** على جعل المهام المتكررة أسهل في الأتمتة. كما أفضل الاحتفاظ بالأوامر داخل سكربتات صغيرة بدلًا من كتابة تسلسلات أوامر طويلة بشكل متكرر.
